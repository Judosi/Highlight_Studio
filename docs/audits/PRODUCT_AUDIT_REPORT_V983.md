# Product Audit: Highlight Studio

## Вердикт

Проект правильный по направлению: он решает понятную боль автора нарезок — из длинного стрима нужно быстро получить готовый YouTube highlight без ручного просмотра всех 3–6 часов.

Сейчас проект уже содержит сильный набор функций: Fast Import, Twitch VOD/Live, Ollama AI, Whisper, OCR, Visual Scan, Review Studio, render, Shorts, metadata и export. Главный риск не в отсутствии функций, а в сложности: пользователь может потеряться, если все 80+ настроек воспринимаются как одинаково важные.

## Главная проблема, которую должен решать продукт

**Проблема:** нарезчик тратит много часов на просмотр стрима, поиск сильных моментов, удаление воды, сборку ролика, создание Shorts и YouTube-метаданных.

**Решение:** приложение должно превращать длинный стрим в набор проверенных моментов и готовый ролик через понятный пошаговый сценарий.

## Что работает хорошо

- Есть локальный AI через Ollama без платных API-ключей.
- Есть Fast Import без копирования больших файлов.
- Есть Twitch VOD/Live import.
- Есть проверки системы: FFmpeg, Ollama, OCR, Twitch tools.
- Есть Review Studio для ручного контроля результата.
- Есть экспорт final video, Shorts, timeline export, metadata.
- Есть пресет под слабое железо GTX 1050 Ti / 16GB RAM / Ryzen 5 2600.
- Есть local auth token для защиты локального API.
- Есть тесты на критичные backend-сценарии.

## Что было неверно и исправлено

- UI мог считать Twitch-проект «готовым», даже если источник ещё не скачан в локальный cache.
- Финальный чек мог считать источник готовым просто потому, что проект существует.
- Кнопки рендера могли быть доступны при проекте без реального `source_video_path`.
- Frontend dependencies имели npm audit warnings; обновлены до безопасных версий.
- Версии в README/backend/UI были рассинхронизированы.

## Что улучшить следующим этапом

1. Сделать один главный режим: «Собрать нарезку».
2. Спрятать 80+ настроек в Pro Mode.
3. Добавить понятные task-пресеты: IRL, спорт, подкаст, смешное, конфликт, Shorts.
4. Показывать AI-объяснение каждого момента простым языком.
5. Добавить диагностику зависаний и ошибок с кнопкой «Как исправить».
6. После рендера показывать финальный отчёт и готовый набор для публикации.
