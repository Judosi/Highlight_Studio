# GitHub Secrets для Windows-релиза

Обязательные для подписанного tag build:

- `WINDOWS_SIGN_PFX_BASE64`
- `WINDOWS_SIGN_PFX_PASSWORD`
- `WINDOWS_CSC_LINK`
- `WINDOWS_CSC_KEY_PASSWORD`
- `HIGHLIGHT_STUDIO_FFMPEG_URL`
- `HIGHLIGHT_STUDIO_FFMPEG_SHA256`
- `HIGHLIGHT_STUDIO_UPDATE_URL`
- `HIGHLIGHT_STUDIO_BETA_UPDATE_URL`
- `HIGHLIGHT_STUDIO_LICENSE_PUBLIC_KEY_B64`
- `HIGHLIGHT_STUDIO_LICENSE_SERVER_URL`
- `HIGHLIGHT_STUDIO_CHECKOUT_URL`
- `HIGHLIGHT_STUDIO_ACCOUNT_URL`
- `HIGHLIGHT_STUDIO_SUPPORT_URL`
- `HIGHLIGHT_STUDIO_PRIVACY_URL`
- `HIGHLIGHT_STUDIO_TERMS_URL`
- `HIGHLIGHT_STUDIO_TELEMETRY_URL`
- `HIGHLIGHT_STUDIO_FEEDBACK_URL`
- `HIGHLIGHT_STUDIO_CRASH_REPORT_URL`

Секреты добавляются в Settings → Secrets and variables → Actions. Не сохраняй PFX и private keys в репозитории.
