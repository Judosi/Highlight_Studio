# Чек-лист дня запуска

- [ ] Release gate без blockers.
- [ ] Installer и engine подписаны.
- [ ] SHA-256 опубликован.
- [ ] Installer проверен на чистой Windows.
- [ ] Stable update feed доступен по HTTPS.
- [ ] License server и backup базы работают.
- [ ] Тестовая покупка выдаёт рабочую лицензию.
- [ ] Отмена подписки обрабатывается корректно.
- [ ] Privacy, Terms, EULA и Refund Policy опубликованы.
- [ ] Email поддержки принимает письма.
- [ ] Сайт и download URL работают.
- [ ] Есть предыдущая версия для rollback.
- [ ] Crash reporting не отправляет данные без согласия.
- [ ] Команда поддержки знает текущие известные проблемы.
- [ ] Реклама запускается постепенно, не на весь бюджет сразу.
