# Shorts Studio: единый редактор

Пользователь поручил проанализировать и реализовать удобную рабочую вкладку Shorts, сохранив приложение и ранее исправленные анализ/монтаж. Работа ведётся в распакованной копии архива, оригинальные вложения не изменяются.

## Решение
Один React-редактор вместо длинной ленты карточек и дополнительного DOM-скрипта. Слева компактный список с поиском и состоянием; справа один ролик: крупный просмотр результата/исходника, название, границы в читаемом формате, кадрирование и текст субтитров. Общие настройки и диагностика раскрываются по необходимости. Сохранение черновика и сборка ролика — отдельные действия. Готовый файл скачивается рядом с просмотром.

## Контракты
- Идентификатор ролика — исходная позиция кандидата (1-based), одинаковая для редактора, API и short_NN.mp4. Сортировка при рендере не меняет эту связь.
- Время принимает секунды с точкой/запятой и HH:MM:SS.ss; пустое/нечисловое значение не превращается в 0.
- Ручной текст отличается от автоматического; пустой ручной текст означает отсутствие субтитров. Автоматический режим не отправляет исходную расшифровку как ручной override.
- Черновики не теряются при опросе статуса, смене вкладки и перезапуске браузера; разделены по проектам. Сохранение в проект защищено от работающей задачи.
- Правки явно отмечают старое видео как требующее пересборки; только успешный рендер меняет статус.
- Единичный рендер не повторяет отбор и не перезаписывает другие Shorts. Пользовательские границы сохраняются точно.
- Настройки, ошибки, пустой список, ожидание и недоступное видео имеют понятные состояния.
- Dark UI, доступные подписи полей, обычные размеры checkbox, responsive layout. Никаких новых runtime-зависимостей.
- Полный Windows архив со встроенной frontend/dist; прежние исправления сохраняются.

## Проверка
Поведенческие React-тесты: выбор/поиск, время 9803.56, invalid interval, черновики, режим субтитров, отказ API, двойное нажатие, download. Python: сохранение/валидация/занятая задача/стабильный индекс. Сборка Vite, проверка существующих hotfix тестов и визуальный просмотр рабочего экрана.
