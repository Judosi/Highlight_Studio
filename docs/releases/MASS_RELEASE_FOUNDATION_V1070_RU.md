# Highlight Studio v10.7.2 — Mass Release Foundation

Эта версия добавляет техническую основу массового выпуска, но не объявляет продукт готовым к массовой продаже без фактических доказательств.

## Обязательные доказательства

- не менее 30 размеченных VOD в benchmark;
- минимум 10 проверенных Windows-конфигураций;
- минимум 100 пользовательских сессий;
- crash-free sessions не ниже 99%;
- подписанные installer и собственные бинарники;
- проверенное обновление с сохранением проектов;
- безопасные HTTPS-службы лицензии, оплаты, поддержки и обновлений;
- опубликованные юридические документы и third-party notices.

Проверка выполняется командой:

```bash
python tools/release/check_mass_release.py --strict
```

Пока есть хотя бы один blocker, сборка может использоваться как закрытая/платная beta, но не должна рекламироваться как массовый стабильный релиз.
