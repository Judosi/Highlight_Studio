Highlight Studio 11.2.6 — улучшение кадрирования Shorts, 16.09.2026

УСТАНОВКА
Закрой приложение. Полностью распакуй ZIP в новую папку. Скопируй projects из
прежней установки, если проекты хранились внутри неё; исходные видео оставь
по прежним путям. Сохрани старую установку до проверки. Для внешней папки проектов
сохрани её настройку. Запусти START_HERE.bat, затем обнови страницу Ctrl+F5.
Первый запуск установит MediaPipe и зависимости через интернет в .venv приложения.
Модель лиц уже в комплекте: при пересборке скачивание модели не требуется.
Node.js для обычного запуска не нужен, готовый интерфейс включён в архив.

ЧТО ДЕЛАЕТ КНОПКА «ПЕРЕСОБРАТЬ РОЛИК»
Сохраняет текущие границы, название, выбранное кадрирование и текст, затем
пересобирает именно этот Short. Прежний файл показывается до успешного завершения.
Если настройки не менялись и кэш актуален, используется уже готовый файл.
«Сохранить правки» само по себе видео не пересобирает.
«Показать безопасную зону» — только направляющая плеера, в MP4 не попадает.
Пустой ручной текст выключает субтитры этого ролика; автоматический текст берётся
из распознавания. Надпись в начале зависит от включения заголовка в настройках.

РЕЖИМЫ
• Весь кадр + размытый фон: сохраняет весь исходный кадр.
• Крупнее по центру + фон: умеренно увеличивает центр, без слежения.
• Обрезать по центру: заполняет 9:16, обрезая края.
• Весь кадр с полями: сохраняет весь кадр на чёрном фоне.
• Следить за лицом: плавное горизонтальное кадрирование по основному найденному
  лицу. Не определяет личность или активного говорящего. При отсутствии лица
  используется увеличенный центр с размытым фоном.
• Игра + веб-камера: ищет устойчивое небольшое лицо в углу и располагает область
  веб-камеры и игру друг над другом. Если веб-камера не найдена, применяется
  кадрирование по лицу; если лиц нет — увеличенный центр с фоном. Компоновка
  эвристическая: после сборки проверь, что выбрано нужное лицо.
• Автоматически: выбирает один из этих вариантов по результатам обнаружения.
При выключенной вертикальной компоновке экспортируется исходный формат.

НОВОЕ
— Обновлена интеграция до MediaPipe Tasks (mediapipe 1.0.1), модель BlazeFace
  включена вместе с Apache-2.0 лицензией, указанием источника и карточкой модели.
— Исправлена ошибка, сводившая все точки движения к последней: камера больше
  не остаётся неподвижной из-за этого сбоя. Точки покрывают всю длину Short.
— До первого обнаружения камера держит начальную позицию без экстраполяции.
— Исправлен сбой обработки узких вертикальных исходников.
— Анализ читает кадры по одному, а не держит весь RGB-клип в оперативной памяти.
— Остановка задачи при анализе лица не маскируется под успешный запасной режим.
— Добавлены объяснения режимов и отчёт «Запрошено / Применено» под результатом.
  Отчёт относится к показанному файлу, а не к несобранному черновику.
  У старых файлов отчёт появится после пересборки. При замене режима видна причина.
— Сохранены предыдущие исправления редактора, Whisper, удаления фрагментов
  и хронологического порядка основной нарезки.

ПРОВЕРЕНО
98 целевых Python-тестов и 16 JavaScript-тестов; Vite build и линтер компонентов.
Реальный FFmpeg: шесть компоновок выдают 1080x1920, узкий вертикальный исходник
обрабатывается, движение кадрирования подтверждено изменением пикселей.
Реальный MediaPipe Tasks: загрузка модели и обработка кадров на CPU.
Проверки выполнены в Linux. Полный Windows-запуск и ускорение GPU/Whisper/Ollama
на твоём ПК здесь не проверены. Интерфейс проверен взаимодействиями в jsdom;
браузерную визуальную проверку локального приложения среда блокирует.
Качество обнаружения зависит от размера, поворота и видимости лица.
Это обновление кадрирования не ускоряет qwen3:8b, работающую на CPU.
