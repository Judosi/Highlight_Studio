Highlight Studio 11.2.6 — новый редактор Shorts

КАК ОБНОВИТЬ
1. Закрой приложение и его окно сервера.
2. Полностью распакуй этот ZIP в новую папку (не запускай из окна архива).
3. Чтобы продолжить старые проекты, скопируй папку projects из прежней установки
   в новую. Сохрани старую установку до проверки. Исходные видео должны оставаться
   по тем же путям. Если проекты находятся во внешней папке, сохрани её настройку.
4. Запусти START_HERE.bat. После открытия страницы нажми Ctrl+F5.
   Сборка интерфейса уже включена; Node.js для обычного запуска не нужен.

КАК РАБОТАТЬ С SHORTS
Экспорт → Shorts. Слева — список с поиском, справа — выбранный ролик.
• «Результат» показывает готовый MP4; «Исходник» — исходное видео без обработки.
  При просмотре исходника можно поставить начало/конец по текущему кадру.
• Границы: 02:43:23.56 или 9803,56. Сотые доли секунды больше не вызывают ошибку
  шага поля. После ручной правки границы не подрезаются автоматически.
• «Сохранить правки» сохраняет в проекте без рендера. Черновики до сохранения
  дополнительно хранятся в этом браузере и разделены по проектам.
• «Собрать/Пересобрать ролик» сохраняет и собирает только выбранный Short.
  Остальные готовые файлы не пересобираются. Новые настройки применяются до запуска.
• «Скачать MP4» находится под просмотром. Если есть правки, старый файл помечен
  как предыдущая версия. После успешной сборки обновляется и ссылка, и плеер.
• Субтитры: «Автоматически из речи» использует выбранный способ распознавания;
  «Мой текст» вшивает ручной текст. Пустой ручной текст убирает субтитры.
• Общие настройки раскрываются сверху. Подборка собирается отдельной кнопкой.
  Сначала сохрани или отмени локальные правки. При изменении параметров отбора
  состав подборки может измениться; сохранившиеся исходные моменты сохраняют правки.
• Технический журнал скрыт в «Подробности задачи и журнал».
• Заголовок в начале Short управляется отдельной галочкой в настройках.
  Это надпись на видео; прежнее исправление порядка большой нарезки сохранено.

ИСПРАВЛЕНО ВНУТРИ
— Убран второй скрипт, который вмешивался в React-редактор и постоянно опрашивал
  сервер. Остался один интерфейс, без дублирующихся карточек.
— Номер кандидата совпадает с short_NN.mp4 даже после сортировки по оценке.
— Пересборка одного Short не запускает новый отбор и работает вне текущего лимита
  количества. Название, границы, кадрирование и ручной текст сохраняются вместе.
— Недопустимые времена и сохранение во время активной задачи отклоняются до записи.
— Старое видео сохраняется при неудачной пересборке, задача показывает ошибку.
— Исправлены статусы старых результатов и обновление кэша плеера после замены MP4.
— Пустые ручные субтитры не возвращаются из старых файлов .srt/.ass.
— Сохранены предыдущие исправления Whisper, удаления в монтаже и хронологического
  порядка большой нарезки (см. UPDATE_ANALYSIS_MONTAGE_RU.txt).

ПРОВЕРКА ЭТОЙ СБОРКИ
98 целевых Python-тестов и 16 JavaScript-тестов прошли, включая реальную сборку
тестового вертикального видео через FFmpeg, сохранение/ошибки/занятую задачу,
индексы роликов, точные границы, ручные субтитры, восстановление черновиков,
повторные нажатия и защиту при переключении проекта. Vite build и компиляция Python
прошли. Проверены новые компоненты линтером.

Полный Windows-запуск, GPU, Whisper/Ollama на пользовательском ПК не проверялись
в этой среде. Автоматический браузер заблокировал доступ к локальному интерфейсу,
поэтому визуальная проверка не заявляется; взаимодействия проверены в jsdom.
Эта сборка не обещает ускорения qwen3:8b на CPU. Наличие дополнительных компонентов
распознавания по-прежнему влияет на доступное качество автоматических субтитров.
