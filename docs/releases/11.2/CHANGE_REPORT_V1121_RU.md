# Highlight Studio 11.2.1 — Montage Quality Recovery

## Исправленная первопричина

На реальном проекте длительностью 2:41:00 Whisper сформировал 35 сегментов с искусственными паузами, а максимальный сегмент растянулся до 267,26 секунды. Старый Micro-cut принимал внешние границы таких сегментов за непрерывную речь, создавал окна до 240 секунд, после чего финальный duration guard молча исключал их. Одновременно prefilter остановился на 16 из 21 допустимого крупного блока.

## Изменения

- Добавлена нормализация транскрипта `speech-gap-v2` по word timestamps.
- Существующий корректный кэш мигрируется на месте без повторного распознавания аудио.
- Micro-cut закрывает окно на большой паузе и применяет жёсткий `micro_max_seconds`.
- Бюджет исходных блоков увеличен с 2× до 4× ориентира с временной стратификацией по всему VOD.
- Dedup prompt получил TIME и PARENT; соседние части одного parent защищены от ложного удаления.
- Refill получил ограниченный quality-recovery tier только для уверенного `primary_live`/`live_reaction`.
- Decision trace различает низкое качество, превышение длительности, overlap и semantic duplicate.
- `analysis_health`, `selection_report` и `quality_report` показывают процент заполнения и явный недобор.
- Whisper `small` стал значением по умолчанию для новых проектов.

## Проверка на предоставленном проекте

- 554 исходных transcript segments → 591 корректных речевых сегментов;
- удалено 2433,01 секунды искусственно включённой тишины;
- максимальный речевой сегмент: 267,26 → 12,73 секунды;
- Micro AI source coverage: 16/21 → 21/21 допустимых блоков;
- микроокна: 43 → 71;
- максимальное микроокно: 45 секунд;
- окон сверх лимита: 0.

Финальный состав сцен требует нового запуска AI, потому что исправленные текст и таймкоды намеренно изменяют block/micro fingerprints.
