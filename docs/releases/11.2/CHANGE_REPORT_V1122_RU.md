# Highlight Studio 11.2.2 — Duration Capacity & Review Feedback

## Исправленная первопричина недобора

В проекте с VOD длительностью 5:45:49.70 было 160 AI-кандидатов общей длительностью более 100 минут. Однако финальная выборка всегда останавливалась на `max_final_segments = 80`, поэтому получила только 37:37.75 при цели 60 минут. Ещё 72 допустимых момента общей длительностью 59:11 оставались с причиной `eligible_but_not_selected`.

Теперь настроенный лимит остаётся минимальной гарантированной ёмкостью, а для длинной цели приложение рассчитывает фактическую ёмкость из целевой длительности и ожидаемой длительности клипа. Для цели 60 минут и микроокна 45 секунд допустимая ёмкость равна 134 фрагментам; для обычной цели 30 минут сохраняется прежний предел 80.

Качественные пороги, semantic guard, защита от replay/технических сцен, overlap и dedup не ослаблены.

## Проверка на данных пользователя

- до исправления: 80 фрагментов / 2257.75 с / 37:37.75;
- после исправления: 109 фрагментов / 3609.74 с / 60:09.74;
- добавлено 29 strict-quality сцен;
- relaxed quality: 0;
- recovery filler: 0;
- заполнение ориентира: 100.27%.

## Быстрое и понятное добавление альтернатив

- нажатие сразу переводит конкретную кнопку в состояние `Добавляю…`;
- повторный клик по тому же моменту временно блокируется;
- верхний индикатор и нижняя панель показывают фактическое сохранение;
- переход к экспорту недоступен, пока запись не завершена;
- после успеха отображается `В монтаже ✓`, при ошибке кнопка возвращается в рабочее состояние;
- backend использует сохранённую ревизию и кэш длительности вместо повторного чтения 16-гигабайтного VOD и лишнего `ffprobe`.

## Совместимость

Старые проекты не изменяются автоматически, чтобы не затереть ручной монтаж. После копирования проекта в 11.2.2 нужно повторно запустить AI-анализ; приложение может использовать уже подготовленные данные, но заново применит исправленный финальный отбор.
