# Highlight Studio v10.8.1 — Windows File Lock Hotfix

Исправлена подтверждённая ошибка Windows `[WinError 5] Отказано в доступе` при атомарной замене `status.json` во время Twitch/VOD задач.

## Исправления

- записи одного JSON-файла сериализуются внутри процесса;
- `os.replace` повторяется при кратковременных WinError 5/32/33 и EACCES/EPERM/EBUSY;
- временная блокировка `status.json` больше не останавливает многочасовую задачу;
- постоянные ошибки диска, например ENOSPC, по-прежнему не скрываются;
- добавлены тесты повторов, конкурентной записи и поведения JobLogger.
