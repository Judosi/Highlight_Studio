# Highlight Studio v10.4.0 — UX Simplification

Версия 10.4.0 основана на рабочем продукте v10.3.0 Release Hardening. Backend-конвейер и подтверждённые исправления безопасности сохранены; основной объём изменений относится к удобству пользователя.

## Главное

- Настоящий простой режим: обычный пользователь видит только основные решения.
- Режим «Профи» сохраняет расширенные AI, Whisper, Twitch, OCR и render-настройки.
- Уведомления разделены на успешные, информационные, предупреждения и ошибки.
- Верхняя панель стала компактнее: название проекта, состояние приложения, режим и меню.
- Навигация разделена на пять этапов создания ролика и отдельные инструменты.
- Экран импорта упрощён; технические параметры Twitch скрыты в дополнительных настройках.
- Убраны пользовательские тексты про старый интерфейс, beta-панель и конкретный компьютер разработчика.
- Настройки в простом режиме сокращены до восьми понятных параметров.
- Добавлен индикатор несохранённых изменений.
- Диагностика переименована и упрощена; упаковочные и отладочные проверки видны только в режиме «Профи».

## Review Studio

- Вместо жёсткого ограничения в 36 кандидатов используется дозагрузка по 60 моментов.
- Показывается, сколько кандидатов загружено из общего количества.
- Кандидат нельзя повторно добавить в монтаж.
- Расширение границ обновляет существующий фрагмент либо добавляет его один раз, не создавая копии.
- Добавлены точные поля начала и конца фрагмента.
- Добавлены Undo/Redo для монтажа.
- Добавлены горячие клавиши:
  - Space — воспроизведение/пауза;
  - A — добавить момент;
  - X — отклонить;
  - стрелки — предыдущий/следующий момент;
  - `[` и `]` — расширить границы;
  - Ctrl+Z / Ctrl+Y — отменить/вернуть.
- Отклонённые кандидаты скрываются и сохраняются локально для проекта.
- Проигрыватель автоматически останавливается в конце выбранного фрагмента.

## Экспорт

- После успешного рендера показывается отдельный спокойный экран результата.
- Главные действия: открыть видео, открыть папку, создать Shorts, подготовить публикацию.
- Добавлено копирование названия, описания и тегов.
- До рендера остаётся одна главная кнопка «Собрать итоговое видео».

## Доступность

- Добавлены focus-visible состояния.
- Добавлены aria-current, aria-live и семантические роли уведомлений.
- Добавлен режим reduced motion.
- Улучшено поведение интерфейса на небольших экранах.

## Проверки

- Backend: 73 теста.
- Frontend: 5 тестов.
- ESLint: успешно.
- Ruff: успешно.
- Vite production build: успешно.
- npm audit frontend: 0 известных уязвимостей.
- npm audit Electron: 0 известных уязвимостей.
- Backend startup и HTTP 200 для встроенного frontend: успешно.

## Что намеренно не имитировалось

В этой версии не добавлена фиктивная waveform. Настоящая звуковая форма для многочасового VOD требует отдельного backend-процесса генерации пиков и кэша. Также не изменён хронологический порядок финальных клипов drag-and-drop: текущий backend нормализует сегменты по времени исходника, поэтому визуальная перестановка без изменения контракта была бы обманчивой.
