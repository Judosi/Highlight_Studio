# Highlight Studio v10.9.1 — Dependency Check Hotfix

Исправлена ошибка Windows-запуска после успешной установки `argon2-cffi`:

```text
missing modules: argon2_cffi
```

Причина: пакет PyPI называется `argon2-cffi`, но импортируется в Python как `argon2`.
Проверяющий скрипт ошибочно преобразовывал имя дистрибутива в несуществующий модуль `argon2_cffi`.

Изменения:

- `argon2-cffi` теперь проверяется через импорт `argon2`;
- добавлен регрессионный тест;
- stamp зависимостей обновлён до `deps_ok_v1091.txt`;
- версия синхронизирована до 10.9.1.
