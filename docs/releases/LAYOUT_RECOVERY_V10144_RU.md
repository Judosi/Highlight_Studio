# Highlight Studio v10.14.4 — восстановление layout и навигации

## Цель

Исправить реальный интерфейс v10.14.3, в котором новый shell конфликтовал со
старыми стилями, а свёрнутая боковая панель не могла быть развёрнута обратно.
Релиз не заменяет рабочую логику приложения: API, проекты и пять этапов остаются
прежними.

## Диагноз

| Симптом | Причина | Исправление |
|---|---|---|
| Панель начинается ниже верхнего края | старый `.studioApp.density-compact .studioSidebar` задавал `top: 78px` | финальная геометрия принадлежит `.studioApp.studioAppV2 > .studioSidebar` |
| Низ панели обрезан | `top: 78px` сочетался с `height: 100vh` | `top: 0` и `height: 100dvh` |
| Меню нельзя развернуть | `.sidebarCollapse` скрывался внутри compact-списка | кнопка всегда видима на desktop и меняет действие/иконку |
| Контент выглядит узким и смещённым | dashboard наследовал старый `max-width`, сцена была ограничена 1280 px | dashboard использует всю сцену, рабочий лимит увеличен до 1520 px |
| Сломанное состояние возвращается после обновления | compact и density сохранялись в `localStorage` | одноразовая миграция v10.14.4 начинает с expanded + comfortable |

## Контракт sidebar

- Desktop expanded: ширина 272 px, полные подписи, кнопка «Свернуть меню».
- Desktop compact: ширина 76 px, иконки и постоянно доступная кнопка
  «Развернуть меню».
- Состояние отражено в `data-sidebar-state`, `aria-expanded`, подписи и иконке.
- После первого сброса v10.14.4 пользовательский выбор снова сохраняется.
- При ширине до 900 px sidebar становится drawer, открывается из command bar и
  закрывается отдельной кнопкой или кликом по затемнению.

## Геометрия и читаемость

- Sidebar и command bar имеют один визуальный ноль без плавающих отступов.
- Обычная рабочая область ограничена 1520 px, Review Studio — 1840 px.
- На широком экране свободное место распределяется симметрично внутри сцены.
- Dashboard переходит в одну колонку при 1180 px, до появления тесных карточек.
- Интерактивные элементы в комфортном режиме имеют высоту не меньше 40 px.
- Заголовок dashboard и основной текст увеличены; compact density оставлена как
  осознанная настройка, а не как проблемный default.

## Защита нужной сборки

- Папка: `Highlight_Studio_10.14.4`.
- Начальный порт: 8144.
- Идентификаторы: `v10.14.4-layout-verified-redesign` и
  `studio-sidebar-layout-v4`.
- Launcher проверяет backend и frontend до открытия браузера.
- Production bundle проверяется на маркеры sidebar, command bar, mobile close,
  Review Studio и состояние навигации.

## Регрессии

Автоматически проверяются:

1. старт в читаемом expanded/comfortable состоянии после обновления;
2. сворачивание и повторное разворачивание без перезагрузки;
3. доступные подписи и `aria-expanded`;
4. финальный CSS-каскад shell;
5. mobile drawer и отдельная кнопка закрытия;
6. совпадение версии во frontend, backend, launcher и архиве;
7. чистая распаковка, SHA-256-манифест и реальный HTTP-запуск.
