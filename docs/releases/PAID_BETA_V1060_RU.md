# Highlight Studio v10.6.0 — Paid Beta foundation

Версия добавляет коммерческий контур поверх v10.5.1: trial, подписанные лицензии, backend-entitlements, приватность, beta-feedback, локальные метрики качества и интеграционные URL оплаты/аккаунта/поддержки.

Внешний платёжный провайдер, настоящий license server, домен и реальные 20–30 тестировщиков не входят в исходный архив. Для них подготовлены безопасные контракты и конфигурация.
