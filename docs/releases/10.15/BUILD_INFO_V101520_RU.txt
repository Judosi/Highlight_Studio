Highlight Studio 10.15.20

Назначение сборки: исправление долгой записи Twitch Live и ложной ошибки по таймауту.

Ключевые изменения:
- Twitch Live теперь показывает прогресс записи по реальному времени до выбранной длительности;
- почти готовый source_live.ts от предыдущего watchdog-сбоя автоматически восстанавливается без повторной многочасовой записи;
- аварийный watchdog сокращён с +300 до +90 секунд после выбранной длительности;
- если FFmpeg достиг watchdog, но source_live.ts уже валиден и почти полностью записан, файл принимается как готовый вместо ложной ошибки;
- частичная короткая запись больше не выдаёт в интерфейс огромный ffmpeg command с подписанным Twitch URL;
- при реальной ошибке показывается записанная и ожидаемая длительность, а частичный source_live.ts сохраняется для диагностики;
- фоновая задача при ошибке больше не показывает противоречивое «Ошибка · 100%» — сохраняется последний реальный прогресс.

Архитектура папок 10.15.18+ сохранена.
