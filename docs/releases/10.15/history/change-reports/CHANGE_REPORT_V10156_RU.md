# Highlight Studio 10.15.6 — Hardware Auto Optimizer

10.15.6 — отдельный релиз поверх 10.15.5. Предыдущая версия не перезаписывается.

## Что исправлено

Главная проблема 10.15.5 заключалась в том, что тяжёлые этапы в стандартной конфигурации оставались CPU-bound: Whisper по умолчанию использовал CPU/int8, final render — libx264, а GPU readiness практически не проверялся. Ручной CUDA-режим мог незаметно упасть обратно на CPU.

В 10.15.6 добавлен capability-based hardware optimizer. Он определяет CPU/RAM/NVIDIA/VRAM, проверяет CTranslate2 CUDA, поддерживаемый Whisper compute type и выполняет реальный NVENC encode probe. Автопрофиль рассчитывается по возможностям фактического ПК, а не по названию одной модели видеокарты.

## Безопасность производительности

На малом объёме VRAM применяется консервативный режим: одна тяжёлая GPU-задача, меньший AI batch, Whisper base и резерв VRAM. Whisper-модель освобождается до перехода к Ollama/visual-этапам. NVDEC намеренно не включается вслепую, поскольку существующие FFmpeg filter graphs остаются CPU-based и лишние transfer могут ухудшить производительность.

Если CUDA или NVENC не запускаются, приложение продолжает работу на безопасном CPU/libx264 пути и сохраняет конкретную причину в диагностике.

## Windows

При наличии NVIDIA обычный launcher проверяет GPU runtime в приватной `.venv` и один раз пытается установить необходимые CUDA/cuDNN Python runtime-пакеты. Если это не удаётся из-за драйвера или несовместимости, запуск приложения не блокируется. Для повторной установки после обновления драйвера оставлен `INSTALL_GPU_ACCELERATION.bat`.
