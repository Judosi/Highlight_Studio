# Highlight Studio 10.15.18 — Architecture Cleanup

## Зачем

В 10.15.18 корень релиза был перегружен историческими отчётами, проверочными BAT, audit-скриншотами и несколькими альтернативными launch-файлами. Это усложняло поддержку и создавало риск путаницы при запуске.

## Изменения

- Корень релиза сокращён до основного launcher, README и обязательных конфигурационных файлов.
- Пользовательские вспомогательные команды собраны в `commands/` по назначению.
- История 10.15.x хранится в `docs/releases/10.15/`.
- Release checks хранятся в `tools/release/checks/`.
- Audit-материалы находятся в `docs/audits/legacy/`.
- YouTube/Web инструкции перенесены в тематические подпапки `docs/guides/`.
- `make_release.py` и `verify_archive.py` используют единый контракт `release_layout.py`, вместо двух длинных рассинхронизируемых списков.
- Добавлен regression-тест структуры папок.

## Совместимость

Основные runtime-каталоги (`backend`, `frontend`, `desktop`, `scripts`, `vendor`) не переносились, чтобы не ломать проверенную цепочку 10.15.18. `START_HERE.bat` остаётся на прежнем месте и запускается так же.
