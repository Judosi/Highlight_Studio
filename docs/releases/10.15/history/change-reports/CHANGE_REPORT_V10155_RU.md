# Highlight Studio 10.15.5 — исправление запуска анализа

10.15.5 — отдельный patch-релиз поверх 10.15.4. Он не заменяет и не перезаписывает предыдущую сборку.

## Исправлено

- `Начать анализ` сразу переводит UI в состояние запуска, без ожидания тяжёлого `dashboard-state`.
- Сохранение настроек перед командой больше не запускает блокирующий refresh; refresh выполняется только после принятия команды backend-ом.
- Устаревший профиль `analysis_profile=safe`, который UI 10.15.4 мог сохранить, автоматически мигрируется в `fast` вместо HTTP 422.
- Опция `safe` удалена из текущих селектов настроек.
- Backend one-click до фонового запуска проверяет подготовленный источник и обязательный runtime и возвращает понятную 422-ошибку, если запуск заведомо невозможен.
- Frontend показывает `recommendation` и первый проваленный preflight-пункт из структурированной backend-ошибки.
- Кнопка анализа не становится полностью «мёртвой» из-за stale UI-флага источника/формата: обработчик может показать, что именно нужно исправить.
- Ollama probe имеет короткий cache для dashboard, но явные system/preflight проверки остаются принудительно свежими.
- Smart preflight приведён к реальной логике pipeline: vision-модель обязательна только для `Средний/Полный`; Twitch downloader не обязателен после готового VOD; <5 GB диска — предупреждение, а не ложный абсолютный запрет.
- При клиентской ошибке optimistic job сбрасывается, чтобы интерфейс не оставался бесконечно в `queued`.
