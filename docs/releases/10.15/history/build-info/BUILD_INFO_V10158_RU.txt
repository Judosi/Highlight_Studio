Highlight Studio 10.15.8 — Manual Review Navigation
Release identity: v10.15.8-manual-review
Design identity: studio-audited-v11

Основные изменения:
- После завершения анализа приложение не переключает этапы автоматически.
- Монтаж доступен по сохранённому analysis revision, а не по candidates.length.
- Завершённый анализ с 0 кандидатами открывает честное пустое состояние монтажа.
- Terminal progress всегда дожимается полным dashboard refresh, чтобы найденные моменты подгрузились.
- One-click больше не пишет «моменты найдены», если кандидат реально 0.
- При открытии проекта сохраняется последний выбранный пользователем этап, если он доступен.
