# Highlight Studio v10.8.0 — Launch Operations Pack

## Назначение

Версия объединяет технический продукт и операционный процесс запуска. Она не заменяет реальные внешние аккаунты, подпись и тестировщиков, но исключает ручное редактирование множества несвязанных конфигов.

## Основные изменения

- launch config и строгая валидация;
- генерация website/Electron/update/deploy конфигураций;
- Docker Compose + Caddy для сайта и license server;
- GitHub Pages deployment;
- GitHub Release publication для Windows tag build;
- CI launch gate;
- runbooks Founders Beta, поддержки, оплаты, DNS и дня запуска;
- CSV/JSON-шаблоны реальной evidence-базы;
- регрессионные тесты launch tooling.

## Ограничения

Сборка не содержит реальных доменов, private keys, платёжных credentials, сертификата подписи и выдуманных benchmark-данных.
