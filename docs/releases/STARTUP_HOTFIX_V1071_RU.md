# Highlight Studio v10.7.2 — Startup Hotfix

Исправлена ошибка Windows-запуска `missing modules: audioop_lts`.

Причина: пакет PyPI называется `audioop-lts`, но предоставляет модуль `audioop`; кроме того, он нужен только на Python 3.13+, а старый диагностический скрипт игнорировал маркер версии Python.

Исправления:

- маркеры requirements теперь вычисляются для текущей версии Python;
- `audioop-lts` проверяется как импорт `audioop`;
- на Python 3.10–3.12 условная зависимость корректно пропускается;
- на Python 3.13+ зависимость устанавливается и проверяется;
- обновлён dependency stamp;
- добавлены регрессионные тесты.
