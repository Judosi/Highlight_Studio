Highlight Studio v11.2.6 Runtime Safety & Atomic Shorts

START_HERE.bat                          — основной безопасный запуск
commands\launch\START_DESKTOP.bat       — local mode without registration
commands\launch\START_WEB_LOCAL.bat     — PostgreSQL + registration + roles
commands\launch\STOP_WEB_LOCAL.bat      — stop PostgreSQL, preserving data

Для режима Web Local установите и запустите Docker Desktop. Остальную настройку выполняет launcher.
