# YouTube Publisher в Highlight Studio

Highlight Studio может загружать готовую нарезку и Shorts напрямую на канал через официальный YouTube Data API v3.

## Что реализовано

- OAuth 2.0 без передачи пароля Google приложению;
- подключение одного YouTube-канала в локальной desktop-версии;
- загрузка обычной нарезки или выбранного Shorts;
- пакетная последовательная загрузка всех готовых Shorts;
- название, описание, теги, категория и видимость;
- флаги «для детей», уведомления подписчиков и изменённого/синтетического контента;
- resumable upload частями по 8 МБ с повторными попытками после сетевых ошибок;
- сохранение прогресса в общем Job Status и ссылок на опубликованные ролики;
- OAuth-токен хранится вне папок проектов в каталоге данных Highlight Studio.

## Первичная настройка Google Cloud

1. Создайте проект в Google Cloud Console.
2. В разделе APIs & Services откройте Library и включите **YouTube Data API v3**.
3. Настройте OAuth consent screen.
4. Если приложение находится в режиме Testing, добавьте свой Google-аккаунт в Test users.
5. Откройте Credentials → Create credentials → OAuth client ID.
6. Выберите тип **Desktop app**.
7. Скачайте JSON-файл OAuth Client.
8. В Highlight Studio откройте проект, перейдите на этап **Экспорт** и выберите вкладку **YouTube**.
9. Загрузите JSON, нажмите «Подключить канал» и подтвердите доступ Google.

## Публикация

1. Выберите проект.
2. Выберите `highlight_final.mp4` или готовый `short_*.mp4`.
3. Нажмите «Взять из Creator Pack» либо заполните метаданные вручную.
4. Для первой проверки оставьте режим «Приватное».
5. Нажмите «Загрузить выбранное» или «Загрузить все Shorts».
6. Следите за прогрессом во вкладке YouTube или в Центре задач.

## Важные ограничения YouTube

- Shorts не имеют отдельного upload endpoint. YouTube автоматически классифицирует квадратные или вертикальные видео длительностью до трёх минут как Shorts.
- Для API-проектов, которые не прошли аудит YouTube, загруженные через `videos.insert` ролики могут принудительно оставаться приватными. Это ограничение Google, а не Highlight Studio.
- Один upload-вызов расходует одну операцию из отдельного дневного лимита Video Uploads. Google указывает стандартный лимит до 100 upload-вызовов в день для проекта API.
- Публикуйте только контент, на который у вас есть необходимые права. Content ID и правила сообщества применяются независимо от способа загрузки.

## Где хранятся данные

В обычной Windows-установке:

```text
%LOCALAPPDATA%\HighlightStudio\youtube\
```

Файлы:

- `client_secrets.json` — OAuth Client из Google Cloud;
- `token.json` — access/refresh token;
- `account.json` — имя и ID подключённого канала.

Эти файлы не входят в экспорт проекта. Не отправляйте их другим людям.

## Отключение

Во вкладке YouTube нажмите «Отключить». Локальный токен будет удалён. При необходимости также отзовите доступ в настройках безопасности Google-аккаунта.
