HIGHLIGHT STUDIO — ГОТОВАЯ СБОРКА С YOUTUBE

1. Распакуйте весь ZIP в отдельную папку.
2. Запустите START_HERE.bat и выберите Desktop.
3. В правом верхнем углу будет красная кнопка «Загрузить на YouTube».
4. Также можно запустить commands\launch\START_YOUTUBE_READY.bat — откроются приложение и экран публикации YouTube.

Для первого подключения понадобится OAuth Client JSON типа Desktop app из Google Cloud.
Подробности: docs\YOUTUBE_PUBLISHER_RU.md
