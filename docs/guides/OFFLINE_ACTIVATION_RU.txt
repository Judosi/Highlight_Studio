HIGHLIGHT STUDIO 11.2.7 — ОФЛАЙН-АКТИВАЦИЯ

В этой сборке исправлена активация при запуске через START_HERE.bat:
backend теперь читает публичный ключ из desktop/electron/paid-beta-channel.json,
если Electron не передал его через переменную окружения.

Для активации нужен подписанный токен HSB1.... от владельца приложения.

1. Запусти START_HERE.bat.
2. Открой Настройки -> Пробный период и активация.
3. Нажми "Скопировать код устройства".
4. Владелец создаёт токен для этого кода через отдельный LICENSE_ADMIN набор.
5. Вставь HSB1.... в поле лицензионного ключа и нажми "Активировать".

Альтернативно полный код устройства можно увидеть через commands\licensing\SHOW_DEVICE_CODE.bat.
Интернет и licenseServerUrl для офлайн-токена не требуются.
