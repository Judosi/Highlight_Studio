# Документация Highlight Studio

- `ARCHITECTURE.md` — актуальная структура проекта.
- `guides/` — пользовательские и эксплуатационные инструкции.
- `releases/` — релизные отчёты и история.
- `changelog/` — patch notes старых веток.
- `audits/` — результаты и материалы аудитов.
- `launch/` — production launch/runbooks.
- `legal/` — юридические документы.
- `templates/` — рабочие CSV/JSON шаблоны.
