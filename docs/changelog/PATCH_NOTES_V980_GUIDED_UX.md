# Highlight Studio v9.8 — Guided Premium UX

Цель: сделать интерфейс красивее и удобнее для реального сценария: загрузить видео → выбрать стиль → запустить AI-анализ → проверить моменты → экспортировать ролик.

## Что изменено

- Добавлен мастер выбора источника на экране импорта:
  - Файл с компьютера;
  - Twitch VOD;
  - Twitch Live.
- Fast Import остался основным рекомендованным режимом для больших файлов 3–6 часов.
- Twitch Import сохранён полностью: VOD/Live, диапазон, live-minutes, cookies browser, threads, yt-dlp format, тест 10 минут, подготовка источника.
- Добавлена карточка текущего видео/проекта:
  - статус источника;
  - тип проекта;
  - storage mode;
  - размер;
  - число AI-кандидатов;
  - число финальных сегментов;
  - состояние финального рендера.
- Добавлен финальный чек перед рендером:
  - проект создан;
  - источник готов;
  - финальные фрагменты есть;
  - pre-render check;
  - длительность рассчитана.
- Улучшен экран настроек:
  - сохранён Stable/Pro Mode;
  - в Pro Mode добавлены все backend AppSettings, включая OpenAI-compatible, preview_resolution и Twitch download settings;
  - настройки Twitch в Pro Mode синхронизируются с видимыми полями импорта.
- Обновлён визуальный слой:
  - новые source cards;
  - project snapshot;
  - render checklist;
  - адаптивные стили для планшетов и мобильной ширины.

## Что не менялось

- Backend endpoints не удалялись и не переименовывались.
- Логика анализа, рендера, OCR, Whisper, Ollama и Twitch pipeline не переписана.
- Существующие кнопки и функции сохранены.
- Опасные действия `Удалить проект` и `Очистить кэш` по-прежнему используют подтверждение.

## Проверки

- `npm run build` — успешно.
- `pytest -q` — 31 тест пройден.
