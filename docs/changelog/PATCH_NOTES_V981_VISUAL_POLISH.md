# Highlight Studio v9.8.1 — Dark Premium Visual Polish

Изменения сделаны безопасным CSS-слоем без изменения backend/API/логики кнопок.

## Что улучшено

- Поля `input`, `select`, `textarea` переведены на тёмный полупрозрачный стиль, чтобы не слепили на тёмной теме.
- Базовые кнопки стали нейтральными glass-кнопками. Главные действия `.primary`, `.primaryStrong`, `.success` остались яркими.
- Фон стал спокойнее: радиальные пятна и сетка менее заметные, меньше визуального шума.
- Карточки и внутренние панели стали минималистичнее, с тёмным glassmorphism-слоем.
- Интерактивные source-карточки получили hover/focus эффекты.
- Добавлены кастомные тёмные scrollbar-правила.
- Сохранены все функции и все элементы управления.
