# v9.7.0 — Premium UX Redesign

Что изменено:
- Полностью обновлён визуальный стиль интерфейса: Midnight Aurora, чистые glass-панели, премиальные карточки, аккуратные градиенты, современные состояния hover/focus.
- Улучшена читаемость навигации: боковой wizard остаётся прежним по логике, но стал визуально понятнее и легче сканируется.
- Переупакованы кнопки, формы, карточки импорта, статуса, таймлайна, настроек и отчётов без изменения API/пайплайна.
- Добавлены более заметные фокус-состояния для доступности и более понятные визуальные акценты для основных действий: импорт, анализ, рендер, экспорт.

Безопасность функций:
- Логика React-компонентов, endpoints backend, параметры settings, действия кнопок и имена API не изменялись.
- Основной редизайн сделан через `frontend/src/styles.css`, чтобы не сломать существующие рабочие сценарии.
- В `App.jsx` изменена только подпись версии в шапке интерфейса.
