# v8.7.6 — AI 100% Strict

Добавлен строгий режим для случаев, когда нужен именно полный AI-анализ, а не быстрые fallback-эвристики.

## Новое

- Кнопка **Включить AI 100%** выставляет безопасные настройки:
  - `ai_strict_mode = true`
  - `full_ai_coverage = true`
  - `metadata_ai_enabled = true`
  - `require_ai_metadata = true`
  - длинные timeout/retry для Ollama
- Кнопка **AI 100% Анализ** запускает анализ без silent fallback.
- Кнопка **AI Metadata 100%** генерирует metadata только через Ollama. Если Ollama не ответила — будет честная ошибка, а не шаблон.
- Новый отчёт `ai_coverage_report.json` показывает:
  - сколько крупных block batch реально обработал AI;
  - сколько micro windows реально обработал AI;
  - были ли failed batches.
- Вкладка **Отчёты → AI 100% coverage** показывает покрытие анализа.

## Поведение strict mode

В обычном режиме приложение может использовать fallback, чтобы не ломать пользовательский сценарий.
В AI 100% режиме fallback запрещён:

- если block AI batch не обработан полностью — анализ останавливается;
- если micro AI batch не обработан полностью — анализ останавливается;
- если Dedup/Storyline AI не отвечает — анализ останавливается;
- если Vision включён и vision-анализ не отвечает — анализ останавливается;
- если AI Metadata неполная или timeout — metadata считается ошибочной.

## Важно

AI 100% режим сильно медленнее. Для 12 GB IRL-стримов это может занять часы, особенно на CPU и с большой моделью.
