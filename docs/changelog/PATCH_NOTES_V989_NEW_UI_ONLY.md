# Highlight Studio v9.8.9 — New UI Only

## Что исправлено

В v9.8.8 была решена часть CSS-проблем, но основной экран всё ещё визуально наследовал старую структуру: системная проверка, Fast Import, Twitch Import, обычная загрузка и Project Manager выглядели как старые отдельные технические блоки.

В v9.8.9 старый интерфейс основного импорта убран из пользовательского сценария. Функции сохранены, но переупакованы в новый единый продуктовый экран.

## Что изменено

- Основной экран теперь называется «Собрать нарезку».
- Добавлен новый hero-блок `NEW PRODUCT UI`.
- Старые равнозначные карточки импорта удалены из основного сценария.
- Fast Import переупакован в новую карточку «Локальное видео».
- Twitch VOD/Live переупакован в новую карточку «Twitch источник».
- Обычная загрузка больше не торчит как отдельная старая карточка; она оставлена как дополнительный инструмент внутри локального источника.
- Project Manager переупакован в компактный блок «Проекты».
- Готовность системы переупакована в правую колонку и больше не выглядит как старый белый dashboard.
- Все элементы остаются в единой dark/glass дизайн-системе.

## Что не удалено из логики

- Fast Import по пути.
- Выбор режима хранения: reference/link/copy.
- Обзор диска.
- Twitch VOD/Live import.
- Тест 10 минут.
- Подготовка Twitch-источника.
- Обычная загрузка маленьких файлов.
- Project Manager: выбор, папка, ZIP, кэш, удаление.
- Backend API, Ollama, Whisper, OCR, Visual Scan, task-пресеты, resume, preflight, render.
