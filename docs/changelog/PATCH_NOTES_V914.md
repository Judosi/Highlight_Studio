# v9.1.4 — Twitch Import + VOD Range

Добавлено:

- Импорт Twitch VOD по ссылке без ручного скачивания пользователем.
- Для Twitch VOD можно задать диапазон анализа: `от` и `до` в формате `HH:MM:SS`, `MM:SS` или секунды.
- Импорт Twitch Live по ссылке на канал: приложение записывает эфир в cache выбранное количество минут.
- Новый backend endpoint: `POST /api/projects/from-twitch`.
- Новый backend endpoint: `POST /api/projects/{id}/twitch-import` для повторной подготовки Twitch cache.
- Новый UI-блок на шаге **Импорт**: `Twitch Import — без ручного скачивания`.
- Добавлены зависимости `yt-dlp` для VOD и `streamlink` для Live.
- Добавлены тесты парсинга Twitch URL, времени и создания Twitch VOD проекта без автозапуска.

Важно:

- Видео всё равно кэшируется локально, потому что Whisper/FFmpeg должны читать байты. Пользователь не скачивает файл вручную — приложение делает это само.
- Для VOD диапазона приложение кэширует выбранный кусок, а не весь стрим.
- Для Live нельзя промотать назад: приложение пишет эфир с момента запуска.
