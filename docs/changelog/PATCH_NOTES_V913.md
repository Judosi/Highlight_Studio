# v9.1.3 — AI Strict Repair

Исправлено поведение AI 100% Strict, когда локальная модель Ollama возвращает неполный JSON и пропускает ID из batch.

Что изменено:
- Добавлен нормализатор AI-ответов: поддерживает `blocks`, `clips`, `items`, `results`, одиночный объект и list-like ответы.
- В AI 100% режиме неполный batch теперь не падает сразу: приложение запускает repair-pass только по пропущенным ID.
- Repair-pass добавлен и для крупных AI batch, и для micro-cut batch.
- Неполный строгий кэш теперь пересчитывается, а не ломает анализ.
- Если после repair-pass ID всё равно не обработаны, ошибка остаётся честной — AI 100% не подменяется эвристикой.

Это исправляет ошибку вида:
`AI 100% режим: AI batch 1 вернул не все ID. Не обработаны: [1, 2]`
