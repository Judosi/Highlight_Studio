# v9.8.7 — Unified Dark Product UI

Исправлена главная визуальная проблема v9.8.6: смешение старых светлых CSS-правил с новым тёмным glass-интерфейсом.

## Что исправлено

- Убраны белые/серые карточки, которые конфликтовали с тёмной темой.
- Исправлены чёрные label-тексты в настройках: теперь все подписи читаемые на тёмном фоне.
- Приведены к одной дизайн-системе карточки, поля, кнопки, source cards, task presets, Review Studio, отчёты и настройки.
- Обычные кнопки стали нейтральными glass-кнопками, а главные CTA остались яркими.
- Поля input/select/textarea полностью адаптированы под dark mode.
- Состояния success/warning/error читаются и больше не выглядят как старый светлый UI.

## Важно

Логика проекта не менялась: импорт, Twitch, Ollama, Whisper, OCR, Visual Scan, Review Studio, Resume, Cache fingerprint, Creator Pack и Render сохранены. Это CSS/визуальная стабилизация плюс обновление версии.
