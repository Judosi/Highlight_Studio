# Patch notes v8.7.3 — IRL Visible Controls

Проблема: у пользователя IRL-настройка была неочевидна/не видна в интерфейсе, хотя backend уже поддерживал IRL.

Исправлено:

- Добавлена верхняя панель **Режим монтажа** сразу под шапкой приложения.
- `Content type` и `A/B режим` теперь всегда видны без поиска в карточках.
- Добавлены быстрые кнопки `IRL плотный`, `IRL история`, `IRL хаос` на видном месте.
- Добавлена кнопка `Сохранить режим` для текущего проекта.
- Обновлена версия приложения до `v8.7.3-irl-visible`.

Проверка: в интерфейсе под названием должно быть `v8.7.3 · IRL Visible Controls`.
