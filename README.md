# Highlight Studio v11.2.7 — Единый центр задач

Аудит текущей сборки: [TECHNICAL_AUDIT_11.2.7_RU.md](docs/releases/11.2/TECHNICAL_AUDIT_11.2.7_RU.md).
Статус: кандидат для проверки, **массовый выпуск заблокирован** до Windows/GPU/реальных VOD и обязательных release gates.

Highlight Studio превращает длинные Twitch VOD и локальные видео в AI-нарезку с ручной проверкой, монтажом, рендером, Shorts и публикацией.

## Запуск

1. Полностью распакуй ZIP в отдельную папку Highlight_Studio_11.2.7.
2. Запусти START_HERE.bat из корня.
3. Для обычной работы больше ничего в корне запускать не нужно.

Дополнительные режимы собраны в commands:

- commands/launch — альтернативный запуск, Web Local и YouTube;
- commands/setup — FFmpeg и NVIDIA/CUDA setup;
- commands/diagnostics — проверка запущенной версии.

## Что изменено в 11.2.7

- При ошибке AI и пустом монтаже сохранённые метаданные не уничтожаются; отмена проверяется до записи.
- Резервная JSON-копия обновляется атомарно только из валидного файла.
- FFprobe отклоняет NaN/нулевую/отрицательную длительность и отсутствие видеопотока.
- Логи редактируют секреты; статус задач отличает локальные метаданные от успешного AI.
- Опрос центра задач не накапливает запросы при медленном backend и прекращается при unmount.
- Единая версия, контроль source/dist, актуальные lock-файлы и пакет документов 11.2.7.
- Реальные DOM-тесты запускаются также на собранном production JS; сохранены проверки manual review.

Полные изменения, результаты и ограничения — в [отчёте](docs/releases/11.2/CHANGE_REPORT_V1127_RU.md).
Автоматический gate на Windows: `tools\release\checks\CHECK_V1127.bat` после установки `backend/requirements-dev.txt` и Node 22+.
Linux native face tracking дополнительно требует системные `libgles2` и `libegl1`; Dockerfile/CI включают их установку.

## Сохранено из 11.2.5

- Creator Pack больше не подставляет название пресета вроде «Сбалансированный / смысл» в название ролика;
- перед генерацией создаётся доказательный паспорт конкретного стрима из финальных сцен, причин отбора и расшифровки;
- выборка охватывает сильные сцены и весь таймлайн, поэтому поздняя часть длинного эфира больше не игнорируется;
- названия обязаны содержать реальное имя, занятие, объект, место, игру, тему разговора или событие;
- описание перечисляет фактические эпизоды выбранного монтажа вместо универсального текста про «эмоции и реакции»;
- конкретные имена, темы и события ставятся в начало списка тегов;
- старые или общие metadata автоматически отвергаются, если их паспорт не совпадает с текущим монтажом;
- AI-ответ проходит specificity audit: слишком общий результат не выдаётся за качественную AI-генерацию;
- при недоступной Ollama создаётся честный локальный пакет из реальных сцен, а не прежних шаблонов;
- главы считаются относительно итогового ролика, а не исходного VOD;
- Micro AI policy не менялась: проверенные checkpoints 11.2.4 используются повторно.

### Проверка на предоставленном проекте

Старый Creator Pack предлагал «ЭТОТ СБАЛАНСИРОВАННЫЙ / СМЫСЛ ВЫШЕЛ ИЗ-ПОД КОНТРОЛЯ» и описание, которое подходило к любому видео. На сохранённых данных пользователя 11.2.5 извлекла реальные темы сцен: конфликт с таймером, попытку восстановить управление, языковой барьер и окончание рейда. В отдельных IRL/gameplay regression-сценариях пакет корректно использовал Лёву, Ростика, парикмахерскую, новую стрижку и FPV Drone Simulator.

## Сохранено из 11.2.4

- ложная классификация текущего gameplay как prerecorded или reconnect исправлена;
- длинная нарезка добирается только безопасным primary-live-контекстом;
- replay, prerecorded, waiting, reconnect, intermission и реклама запрещены для добора;
- добавленный связующий контекст виден в Review Studio и удаляется вручную;
- на сохранённых данных проблемного проекта результат исправленного отбора составил 35:00 вместо 7:23.

## Сохранено из 11.2.1

- исправлены многоминутные ложные интервалы Whisper;
- микроокна больше не пересекают большие паузы;
- дедупликация различает повтор и соседние части одной сцены;
- недобор длительности честно отражается в статусе и отчётах;
- для новых проектов Whisper по умолчанию использует модель small;
- все исправления стабильности, source resolver и Atomic Shorts сохранены.

Технический аудит и ограничения: docs/releases/11.2/TECHNICAL_AUDIT_11.2.5_RU.md.
