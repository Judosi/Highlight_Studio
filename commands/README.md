# Команды Highlight Studio

Корень приложения намеренно оставлен чистым: для обычного запуска нужен только `START_HERE.bat`.

- `launch/` — альтернативные режимы запуска и публикации.
- `setup/` — установка/восстановление внешних зависимостей.
- `diagnostics/` — ручные диагностические команды.

Все BAT-файлы сами определяют корень приложения, поэтому их можно запускать непосредственно из этих папок.
